# Voice Assistant

## Project Overview

This project is a Python-based voice assistant developed as part of the Oasis Infobyte Python Programming Internship.

The voice assistant accepts commands through a microphone, converts speech into text, processes the command, and responds using text-to-speech.

## Features

- Voice input through microphone
- Speech recognition
- Text-to-speech responses
- Greeting the user
- Current time
- Current date
- Web search
- Open Google
- Open YouTube
- Open Spotify
- Tell random jokes
- Help command
- Graceful exit
- Error handling for unclear speech and service errors

## Technologies Used

- Python
- SpeechRecognition
- Pyttsx3
- PyAudio
- Datetime
- Webbrowser
- Random
