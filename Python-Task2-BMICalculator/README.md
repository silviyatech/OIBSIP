# BMI Calculator

A Python-based BMI Calculator developed as part of the Oasis Infobyte Python Programming Internship.

## Task

**Task 2 - BMI Calculator**

## Description

This project is a graphical BMI Calculator developed using Python and Tkinter. It allows users to enter their name, weight, and height and calculates their Body Mass Index (BMI).

The application also classifies the BMI into different categories and stores previous records for future reference.

## Features

- Calculate BMI using weight and height
- BMI displayed up to 2 decimal places
- BMI category classification
- Input validation
- Save BMI records
- View BMI history
- SQLite database for storing records
- BMI history graph
- Clear input fields
- User-friendly graphical interface

## BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 - 24.9 | Normal |
| 25.0 - 29.9 | Overweight |
| 30.0 and above | Obese |

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib
