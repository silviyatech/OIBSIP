# Weather App

A Python-based Weather App developed as part of the Oasis Infobyte Python Programming Internship.

## Task

**Task 4 - Weather App**

## Description

This project is a graphical Weather App developed using Python and Tkinter.

The application allows users to search for the current weather information of any city. It retrieves real-time weather data using the OpenWeatherMap API and displays important weather details in a simple and user-friendly interface.

## Features

- Search weather by city name
- Display current temperature
- Display weather description
- Display feels-like temperature
- Display humidity
- Display wind speed
- Display atmospheric pressure
- Real-time weather data using API
- Error handling for invalid cities
- Network error handling
- API error handling
- Clear search and weather information
- Press Enter to search
- User-friendly graphical interface

## Technologies Used

- Python
- Tkinter
- Requests
- OpenWeatherMap API

## Weather Information

The application displays:

- City and country
- Current temperature
- Weather condition
- Feels-like temperature
- Humidity
- Wind speed
- Atmospheric pressure

This project uses the OpenWeatherMap API to retrieve real-time weather information.
